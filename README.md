# WebCraft Multi-Tenant Agency SaaS Builder

Enterprise multi-tenant website builder and agency management platform featuring Stripe billing and custom subdomains.

---

## 🚀 Tech Stack
`Next.js 14` `TypeScript` `Stripe API` `Tailwind CSS` `Prisma` `PostgreSQL`

---

## ✨ Key Features
- **Multi-tenant**: agency and client subaccount architecture
- **Visual**: drag-and-drop website funnel and page builder
- **Integrated**: Stripe subscription billing with multi-tier pricing plans
- **Custom**: domain mapping and automated SSL routing
- **Comprehensive**: agency analytics, revenue reporting, and client management

---

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+) or Python (3.10+) depending on project requirements
- Git

### Installation
```bash
# Clone the repository
git clone https://github.com/aqsam-husnain/webcraft-saas-builder.git

# Navigate into project directory
cd webcraft-saas-builder

# Install dependencies
npm install  # or: pip install -r requirements.txt

# Run the development server
npm run dev  # or: python app.py
```
